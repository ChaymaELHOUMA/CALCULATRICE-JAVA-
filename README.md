# Calculatrice Java

## Description
Projet d'une **calculatrice simple en Java** utilisant **Swing** pour l'interface graphique.  
Elle permet de réaliser les opérations de base : addition, soustraction, multiplication et division.  
Ce projet est idéal pour apprendre la programmation Java et la création d'interfaces graphiques.

---

## Fonctionnalités
- Interface graphique conviviale avec boutons pour chaque opération.  
- Gestion des nombres à virgule.  
- Possibilité de réinitialiser la calculatrice.  
- Gestion des erreurs simples (ex: division par zéro).

---


## Prérequis
Avant d'exécuter le projet, assurez-vous d'avoir :  
- Java JDK 8 ou supérieur installé  
- IntelliJ IDEA ou un autre IDE Java installé
